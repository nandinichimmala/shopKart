# ShopKart - E-Commerce Website

## 1. Project Description
ShopKart is an e-commerce website inspired by Amazon. It allows users to browse product categories and view product details through a simple and user-friendly interface.

## 2. Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 3. Features Implemented
- E-commerce homepage
- Product category cards with clickable images
- Separate product listing pages
- Product images, names, and prices
- Product search
- Category filtering
- Add to Cart functionality
- Cart product count
- Responsive layout

## 4. Instructions to Run the Project
1. Open the GitHub repository.
2. Click **Code** and download the ZIP file, or clone the repository.
3. Extract the project files if downloaded as a ZIP.
4. Open the project folder in Visual Studio Code.
5. Open `index.html` in a web browser, or use the Live Server extension.
6. Test the product pages and available features.

## 5. Challenges Faced During Development
- Organizing product images and maintaining correct image paths.
- Linking category cards to product pages.
- Designing product cards using CSS.
- Implementing JavaScript functionality.
- Deploying the website using GitHub Pages.

## 6. Evaluation Criteria
- Website design and layout
- HTML, CSS, and JavaScript implementation
- Search and category filtering
- Add to Cart functionality
- Responsive design
- Working navigation and image links
- Code organization
- Successful deployment
